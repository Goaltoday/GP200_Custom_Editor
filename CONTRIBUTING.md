# Contributing

Build the Windows application with `scripts/build-app.ps1`. Preserve preflight, backups, ownership, readback and no automatic resending of uncertain writes. Describe behavior changes and any hardware requirements clearly in the pull request.

Do not contribute firmware images, proprietary artwork, commercial models/IRs, secrets or private device logs. Use original unbranded graphics and retain provenance and third-party notices. Contributions to project-owned files are submitted under GPL-3.0-only unless explicitly agreed otherwise.
